# Code of Conduct

## Our Commitment

We want this project to be welcoming and respectful for everyone.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent.
- Give actionable, technical feedback.
- Focus on improving the project.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Discrimination or hateful language.
- Publishing private information.
- Repeated disruptive behavior in issues/PRs.

## Enforcement

Project maintainers may edit, lock, or remove content that violates this code.
Repeated or severe violations may result in blocking from participation.

## Reporting

Open a private GitHub discussion with maintainers or create an issue marked as conduct-related.
